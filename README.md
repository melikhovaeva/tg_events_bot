# TG Events Bot

MVP для отбора гостей: регистрация в Telegram → ручное приглашение → ответ в Telegram → напоминание → QR-чек-ин.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и заполните `.env` по примеру `.env.example`.
2. Установите зависимости: `npm install`.
3. Запустите: `npm start`.
4. Откройте `http://localhost:3000/admin` и войдите с `ADMIN_PASSWORD`.

В админке создайте событие. Откройте его и скопируйте ссылку на регистрацию — её можно публиковать в канале, сторис или на лендинге. В боте человек увидит карточку события, введёт ФИО, подтвердит номер телефона и автоматически передаст свой Telegram username (если он задан в профиле). Заявка сразу появится в админке, где её можно пригласить одной кнопкой.

## Что автоматизировано

- приглашение и подтверждение/отказ в боте;
- автоматическое закрытие приглашения через 24 часа;
- ссылка на чат после подтверждения;
- напоминание за 24 часа до начала;
- одноразовый QR для чек-ина и ручной запасной код;
- экспорт списка гостей в CSV.
- ФИО, обязательный номер телефона и Telegram username в каждой заявке.

Telegram username нельзя получить, если человек не задал его в настройках Telegram: в этом случае в админке будет показано «Username не задан», но Telegram ID всё равно останется привязан к заявке.
